# Security policy

Only the latest version of Tweet Grabber receives fixes. Update the extension or the userscript before reporting a problem.

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead from the repository's [Security tab](https://github.com/danielgsanchez/tweet-grabber/security/advisories/new).

Include what an attacker could do, the steps to reproduce it, and whether it affects the extension, the userscript or both. You'll get a reply as soon as possible, and the fix will be published in a new release.
